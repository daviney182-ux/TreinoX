# treinoX

treinoX é um app de treino feito para o celular, criado por Junior. Você escolhe o seu biotipo e recebe um plano de treino da semana pensado para ele, com cronômetro para marcar as séries e acompanhar o seu progresso. Tem uma aba de alimentação com as refeições do dia e, no plano VIP, calculadoras e conquistas para manter a motivação. O app funciona em vários idiomas, de acordo com o seu país, e tem um visual escuro e moderno, com uma barra de navegação em vidro que desliza entre as abas. O VIP custa R$ 7,52 por mês ou R$ 79,00 por ano, com pagamento por Pix.

Site estático: o arquivo principal é `index.html`.
